# Reference dictionary

| Term       | Meaning                                                                                                                                                                                                                |
| ---------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Drytails   | Colloquial name for land-based troops, in contrast to merfolk. They need bridges or shallow crossings to reach islands, rather than swimming through open water. This is a nickname, not a separate race or unit type. |
| White wolf | [Saved pale dire wolf reference](white-wolf/README.md), with editable matrices and both faction renders. Candidate for a special unit in a future campaign.                                                            |
