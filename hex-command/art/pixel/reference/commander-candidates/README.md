# Commander candidates

The selected directions are a dwarf Forge lord and an elf spear-and-banner lord.
These crowned L1 designs became the approved bases of the
[canonical commander progressions](../commander-progression/README.md).
All three tiers are now in main unit assets; gameplay registrations are unchanged.
Native matrices
and palettes are saved beside generation evidence, exact prompts, template manifests
and explicit crown/local-cleanup edit logs preserve the initial L1 work.

Both candidates used three approved references and one fill box. Dwarf remains
48×48, elf 64×64. Crown additions preserve faction ownership: only mantle, apron
tab and elf pennant change by side. Detector flags remain review candidates;
these units have not been declared free of every extraction defect.

Use the project [pixel-cleaning skill](../../../../.agents/skills/pixel-cleaning/SKILL.md)
and [enhancement skill](../../../../.agents/skills/pinkbox-enhancement/SKILL.md)
for further changes.
