# Ashen Oath with the exact enemy-turn forecast

These independent Luna trials use frozen `06da43c`. The complete transcripts were
replayed by that engine; [results.json](results.json) records every attempt.

| New recruitment                  | Opening attempt | Retry          | Campaign complete |
| -------------------------------- | --------------- | -------------- | ----------------- |
| Mixed skeletons and bone archers | Defeat, turn 14 | Defeat, turn 7 | No                |
| Skeleton only                    | Defeat, turn 7  | Defeat, turn 8 | No                |

Both policies lost Orin before reaching the gate. Equal failure is not evidence
that the campaign is well balanced. The players had an exact forecast, but their
choices and risk handling still differed; this remains one sample per policy.

The opening has since been revised to use rookie swordsmen for its initial guard
and ordinary recruitment. The later adept and veteran warden reinforcements
remain an escalation. These archived outcomes predate that change and must not
be reported as results for the revised encounter.
